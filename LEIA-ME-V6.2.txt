CARTEIRINHA GAMER V6.2 — LOGIN + SAVE NA NUVEM

O que mudou
- Banner 4K reposicionado: a arte ocupa melhor a parte direita sem esmagar o texto.
- O bloco "Explore por categoria" foi removido do Hub por enquanto.
- No lugar dele entrou "Conta & nuvem".
- Nova página login.html.
- Nova página cadastro.html.
- Nova página conta.html com envio/recuperação manual do save.
- O botão Entrar do topo agora abre a conta real.
- Perfil, biblioteca, histórico e dados de publicação podem ser sincronizados com D1.
- Ao criar a primeira conta, o site detecta a Carteirinha já existente no navegador e pergunta se deseja enviar esses dados para a nuvem.
- Depois do login, alterações feitas pelo site disparam sincronização automática com pequeno atraso.

IMPORTANTE — PARA O LOGIN FUNCIONAR DE VERDADE
O frontend já está pronto, mas o Cloudflare Worker que está publicado hoje ainda não conhece as novas rotas.

No Cloudflare:
1. Abra o mesmo Worker da Carteirinha Gamer.
2. Faça uma cópia do código atual por segurança.
3. Substitua o código pelo arquivo: worker-v6.2-login-cloud.js
4. Salve/Deploy.
5. O binding D1 deve continuar com o nome DB, como já está no projeto.
6. RAWG_API_KEY e STEAM_API_KEY continuam como antes.

As tabelas de conta são criadas automaticamente na primeira chamada da API.
O arquivo migracao-v6.2.sql também está incluído caso você prefira criar as tabelas manualmente no painel do D1.

Rotas novas
POST /auth/register
POST /auth/login
GET  /auth/me
POST /auth/logout
GET  /save
PUT  /save

Senhas
- A senha nunca é salva em texto normal.
- O Worker usa PBKDF2-SHA256 com salt individual e 210.000 iterações.
- Sessões usam token aleatório e o banco guarda somente o hash do token.
- Sessões expiram em 30 dias.

Teste recomendado
1. Primeiro abra index.html localmente e confira o novo enquadramento do banner.
2. Abra cadastro.html. Antes do deploy do Worker, a criação de conta retornará rota não encontrada — isso é esperado.
3. Faça o deploy do worker-v6.2-login-cloud.js.
4. Crie uma conta.
5. Quando aparecer "Encontramos uma Carteirinha salva neste navegador", escolha vincular os dados.
6. Abra conta.html e confira se o save na nuvem aparece.
7. Faça uma alteração no perfil/biblioteca e aguarde cerca de 1 a 2 segundos.
8. Em outro navegador/dispositivo, faça login e escolha carregar o save da nuvem.

Backup
Antes de testar migração de conta, continue guardando seu backup JSON atual. Esta é a primeira versão do sistema de conta e sincronização.
