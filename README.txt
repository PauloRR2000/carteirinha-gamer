CARTEIRINHA GAMER — PROTÓTIPO V1

Páginas:
- index.html          Página inicial
- dashboard.html      Central Gamer
- biblioteca.html     Tabela/planilha de jogos
- jogo.html           Adicionar e editar jogos
- carteirinha.html    Carteirinha Gamer completa
- perfil.html         Perfil e habilidades
- historico.html      Histórico das alterações

Arquivos principais:
- style.css           Todo o visual do site
- script.js           Toda a lógica, localStorage e interações

COMO TESTAR
1. Extraia a pasta.
2. Abra a pasta no VS Code.
3. Use uma extensão como "Live Server" para abrir index.html.
4. Entre com um nome.
5. Adicione jogos.
6. Edite o perfil e escolha um favorito.
7. Edite um jogo já salvo para gerar histórico.

IMPORTANTE
- Este é um protótipo local de treino.
- "Login" não é autenticação real.
- Os dados ficam no localStorage do navegador.
- Não há banco de dados nem backend.
- Notícias e publicidade são apenas áreas demonstrativas.
